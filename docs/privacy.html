Privacy Policy

Last updated:

The short version: Viper Suite does not collect, transmit, or share any of your data. Everything stays on your own infrastructure or device.

1. Overview

Viper Suite is open-source, self-hosted software developed by Serpens Tech. This policy applies to the Viper Suite software, including the web client, desktop applications, and Android apps.

Because Viper Suite is self-hosted, you — not Serpens Tech — operate the server that stores and processes all data. Serpens Tech has no access to your data at any point.

2. Data We Do Not Collect

Serpens Tech does not collect, store, or have access to any of the following:

  • Personal information (name, email address, etc.)
  • Account credentials
  • Tasks, lists, income, or expense entries
  • Usage data, analytics, or crash reports
  • Device identifiers or IP addresses
  • Any other user-generated content

3. How Data Is Stored

All data is stored in one of two ways, depending on how you use the app:

  • Server mode: Data is stored in a PostgreSQL database on the server you deploy and control. Serpens Tech has no connection to your server.
  • Local mode (desktop & Android only): Data is stored in the local storage of the device running the app. No network connection is made.

4. Third-Party Services

The Viper Suite software itself uses no third-party analytics, tracking, or advertising services.

If you choose to host Viper Suite on a cloud provider, that provider's own privacy policy applies to the infrastructure you use. Serpens Tech has no involvement in or control over that arrangement.

5. Open Source

Viper Suite is fully open-source under the Apache License 2.0. You can inspect every line of code to verify the claims in this policy.

6. Store Distributions

If you download Viper Suite through Google Play or the Microsoft Store, those platforms may collect data according to their own privacy policies. Serpens Tech does not receive any such data.

7. Changes to This Policy

If this policy is updated, the new version will be published at this URL with a revised date. Because Viper Suite collects no user data, changes are unlikely to affect you in any meaningful way.

8. Contact

For any questions about this policy, contact us at viper@serpens-tech.com.
