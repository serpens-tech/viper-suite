Dve aplikacije, jedan server

Sve što vam treba da ostanete organizovani

Viper Suite dolazi sa dve aplikacije koje dele isti backend i bazu podataka u potpuno self-hosted okruženju.

Crossed Viper

Upravljanje zadacima i listama

  • Više lista zadataka sa prioritetima i rokovima
  • Admin panel za upravljanje korisnicima
  • Finansijske oznake — označite zadatke kao prihod ili rashod
  • Završetak finansijskog zadatka automatski kreira budžetski unos
  • Podrška za tamni mod (najvažnija stvar)

Leaf Viper

Praćenje prihoda i rashoda

  • Praćenje prihoda i rashoda sa tekućim stanjem
  • Automatski unosi iz završenih finansijskih zadataka iz Crossed Viper-a
  • Istorija transakcija po datumu
  • Admin panel za upravljanje korisnicima
  • Podrška za tamni mod (najvažnija stvar)

Pokretanje servera

Pokrenite sopstveni server za nekoliko minuta

Pokretanje servera je preporučeno — omogućava punu sinergiju između Crossed Viper-a i Leaf Viper-a, sa deljenim nalozima, automatskim budžetskim unosima i pristupom sa svakog klijenta. Potrebni su samo Docker i Git.

Ako ne želite server, desktop i Android aplikacije mogu čuvati sve podatke lokalno na uređaju kao alternativu.

1

Klonirajte repozitorijum

git clone https://github.com/serpens-tech/viper-suite.git && cd viper-suite

2

Pokrenite aplikaciju

docker compose up -d — pokretanje FastAPI backend-a i PostgreSQL baze podataka.

3

Pregledajte detalje podešavanja

Otvorite README projekta na GitHub-u za kompletna uputstva i podrazumevane kredencijale.

4

Promenite podrazumevanu lozinku

Idite u Admin panel i odmah ažurirajte kredencijale.
