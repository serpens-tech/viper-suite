Two apps, one server

Everything you need to stay organised

OpenWeb ships with two apps that share a single self-hosted backend and database, but work completely independently.

OpenTask

Task & to-do management

  • Multiple task lists with priorities and due dates
  • User accounts with JWT authentication
  • Admin panel for managing users
  • Finance flags — mark tasks as income or expense
  • Completing a finance task auto-creates a budget entry
  • Dark mode support

OpenBudget

Income & expense tracking

  • Track income and expenses with running balance
  • Automatic entries from completed OpenTask finance tasks
  • Date-based transaction history
  • Clean, minimal interface
  • Dark mode support

Setup

Up and running in minutes

All you need is Docker and Git. No databases to configure, no cloud accounts, no environment files to edit.

1

Clone the repository

git clone https://github.com/your-username/openweb.git && cd openweb

2

Start the application

docker compose up -d — starts the FastAPI backend and PostgreSQL database.

3

Open in your browser

Visit http://localhost:8000 and pick an app. Default login: admin / admin123.

4

Change the default password

Go to the Admin panel and update your credentials immediately.
